# Touchpad Gestures

> 一个 macOS 菜单栏 App，通过自定义触控板手势调节系统音量、亮度与媒体进度。
> 双击触控板边缘保持滑动，或 Force 按压保持滑动，精确调节，带刻度震动反馈。

## 功能

### 手势与调节
- **双击边缘保持 + 滑动**：右边缘调音量、左边缘调亮度
- **Force 按压手势**：重按边缘保持进入调节（压力阈值 / 保持时长可调，带迟滞防抖）
- **媒体进度调节（seek）**：上边缘横向滑动快进/快退，下边缘同款手势默认关闭
- **系统 HUD 联动**：媒体键模式自动唤起系统音量/亮度指示框
- **边界检测**：到达 0% / 100% 时值自然停住（系统 clamp），不会卡中间
- **鼠标锁定**：手势期间光标原地不动，避免误触

### 反馈
- **刻度震动反馈**：滑动每格一次轻震动，可独立配置波形 / 次数 / 间隔
- **自定义触觉波形**：不限于预设，可自建波形（包络 + 音调 + 力度乘法器），实时试听

### 配置
- **节点图画布编辑器**：整张手势行为（识别 / 信号 / 震动 / 鼠标）用 Blender 风格节点图可视化编辑，支持模块折叠、自动整理、框选复制粘贴
- **基础设置页**：卡片式高层配置（绑定 / 识别 / 信号 / 触觉），与画布双向同步，降低学习成本
- **完全可配置**：所有参数暴露在 UI 中，支持单项重置 / 全局重置 / 保存为默认
- **手势启用开关**：每个手势可独立启用 / 禁用，立即生效
- **形态识别**：独立页——手指识别（接触面积范围）+ 手掌过滤开关 + 触摸阶段参考
- **语言切换**：跟随系统 / 中文 / English，即时生效

### 外观与启动
- **菜单栏图标 / App 图标颜色 / Dock 显示开关 / 开机自启动**
- **单实例保护**：重复启动会自动激活已有实例，避免多个图标与多引擎抢触控板

## 系统要求

| 项 | 要求 |
|---|---|
| 系统 | **macOS 15 (Sequoia) 或更高** |
| 硬件 | MacBook 内置触控板（MultitouchSupport.framework 兼容机型） |
| 权限 | **「辅助功能」**（模拟媒体键以触发系统 HUD） |
| 权限 | 「输入监控」**无需**授予 |

> **关于「输入监控」**：触控板数据走 MultitouchSupport 私有框架，**不受 TCC 输入监控门控**，
> 因此本 App 既不请求该权限，也不需要它。若你在系统设置里看到本 App 出现在「输入监控」列表，
> 忽略即可——授予与否都不影响功能。

## 使用方法

1. 启动后菜单栏出现 `hand.tap` 图标
2. 点击图标 →「设置...」打开配置界面
3. **双击边缘**：快速双击触控板右/左边缘并保持 → 上下滑动调节音量 / 亮度
4. **Force 按压**：重按触控板右/左边缘并保持（压力 ≥ 阈值持续一段时间）→ 上下滑动调节
5. **媒体进度**：在上边缘横向滑动 → 快进 / 快退
6. 到达 0% / 100% 时值停住，继续滑动不会卡死，反向滑动立即恢复

### 修饰键精准调节

滑动时若同时按着键盘修饰键，会被一并注入到合成的媒体键事件中，可使用系统原生组合：

| 组合 | 效果 |
|---|---|
| **⌥ + ⇧ + 滑动** | 音量 / 亮度进入 **1/4 格精准档位** |
| **⇧ + 滑动** | 静音等系统原生行为 |

### 菜单栏菜单

| 项 | 说明 |
|---|---|
| 设置... | 打开配置窗口（`⌘,`） |
| 触控板状态 | 显示初始化中 / 就绪（N 个设备）/ 失败原因 |
| 重试初始化 | 仅在初始化失败时显示，用于重试（如刚授予权限后） |
| 退出 | 退出 App（`⌘Q`） |

> 关闭设置窗口**不会**退出 App，菜单栏图标会继续驻留。

## 配置说明

设置窗口左侧为一级导航：

| 页 | 内容 |
|------|------|
| **手势** | 基础设置（绑定 / 识别 / 信号处理 / 触觉反馈）或高级画布（节点图编辑） |
| **事件** | 动作目标（音量 / 亮度 / 媒体进度）、方向映射、执行方式（媒体键 / 直接 API）、步长、边界阈值 |
| **区域** | 手势触发区域矩形坐标 + 可视化预览 |
| **形态识别** | 手指识别（接触面积范围）、手掌过滤开关、触摸阶段参考 |
| **波形** | 自定义触觉波形（包络 / 音调 / 力度乘法器）编辑、试听与预设管理 |
| **设置** | 语言、触摸数据流、触控板规格、软件信息、手势健康、启动、菜单栏图标、App 图标、诊断日志、配置默认值 |

### 三种动作目标

| 目标 | 实现方式 | HUD |
|---|---|---|
| **音量** | 媒体键（`NX_SYSDEFINED`）或 CoreAudio 直接赋值 | 媒体键模式有 HUD |
| **亮度** | 媒体键或 IOKit `IODisplaySetFloatParameter` | 媒体键模式有 HUD |
| **媒体进度** | AX API 操作焦点 App 的 AXSlider，失败时回退方向键 | 无 |

### 节点图触发时机

每个手势是一张自由节点图，图的入口可绑定到以下时机：

| 触发时机 | 说明 |
|---|---|
| 第一次轻点 | 首次落指 |
| 第二次轻点 | 双击的第二次落指 |
| 进入保持 | 双击保持成功、进入调节态 |
| 刻度触发 | 滑动中每次量化触发 |
| 到达边界 | 首次到达 0% / 100% |
| 退出保持 | 手指抬起、退出调节态 |

## 自定义触觉波形

「波形」页可以完全自定义震动的手感，而不只是从预设里挑一个。

### 可调参数

| 分组 | 参数 | 作用 |
|---|---|---|
| **包络** | 类型、幅度、时长 | 决定"敲击感"的力度与轮廓 |
| **音调** | 类型（Sine / Square）、频率、幅度、时长、延迟 | 决定音色 |
| **力度乘法器** | Light / Medium / Firm × （包络 / 音调） | 按按压力度分档缩放 |

编辑时波形图实时预览，可直接**试听**对照。

### 内置预设

| ID | 手感 |
|---|---|
| 1 | 弱 click |
| 2 | 强 click（Force Touch） |
| 3 | buzz 震颤 |
| 4 | 轻 tap |
| 5 | 中 tap |
| 6 | 强 tap |
| 15 / 16 | 软重击（无包络 + 纯低频长音） |

在此之上，自定义波形走私有 `MTActuationCreateFromDictionary` 编译波形 + waveformID 83
宿主自定义槽位下发，**与 Apple 预设波形互不干扰**。

> **可靠性**：若某机型 / 系统版本缺少该私有符号，会自动**回退到预设波形**，
> 保证任何情况下都仍有震动反馈，而不是静默失效。

## 技术实现

### 触控板数据链路

- **MultitouchSupport.framework**（Apple 私有框架）：`dlopen` / `dlsym` 动态加载，避开 ARM64e PAC 指针认证，获取 96 字节/手指的 `MTTouch` 结构化数据
- **C 桥接层** (`mt_bridge`)：设备发现、触摸回调、触觉反馈；对私有回调的 `n_fingers` 做边界钳制
- **私有结构偏移**：`MTDeviceGetDeviceID()` 在 Apple Silicon 上会触发 SIGBUS，故改从 `MTDevice` struct offset 64 读取，并以 IORegistry 的 `mt-device-id` 交叉校验

### 节点图执行引擎（`GestureEngine`）

- 手势 = **单张自由节点图**；识别状态机（轻点 / 双击 / Force / 计时 / 漂移）、信号管线（变换 / 量化）、反馈（震动 / 调节 / 鼠标）**全部是图节点**
- **摩尔状态机语义**：帧首读旧值、帧尾统一写，状态转移用旧状态判断、新状态下一帧生效
- **固定步长帧循环**（Godot 式）：MT 回调只更新触摸快照，逻辑由固定 tick 驱动
  - 活跃期 120Hz，确认空载后降到 **20Hz** 省电；触摸到达立即恢复全速
  - 快照**陈旧判定**：MT 回调停止超过阈值即视为手指离开，喂空帧把状态机拉回 idle
    （否则冻结帧会让引擎 120Hz 满耗且不自愈）
  - 时间累积器 + 防追赶螺旋（长停顿直接丢弃增量）

### 系统副作用

- **媒体键模拟**：`NX_SYSDEFINED` 系统事件触发系统 HUD；修饰键经线程安全的 `CGEventSource.flagsState` 读取
- **鼠标锁定**：`CGAssociateMouseAndMouseCursorPosition` + 每帧 `CGWarpMouseCursorPosition`

### 配置持久化

- JSON 存储，含 v1 / v2 → 当前版本的自动迁移链
- **损坏防护**：配置无法解析时隔离备份为 `config.corrupt-<时间戳>.json` 并告警，绝不原地丢弃
- **写入防抖**：界面连续编辑（如拖动滑杆）合并为 300ms 一次落盘，退出时强制刷盘
- **结构卫生**：解码时去重节点 id、清理悬空边，避免重复 id 导致崩溃

## 数据与隐私

- **无网络请求**：本 App 不联网，不收集、不上传任何数据
- **本地存储**：配置仅保存在
  `~/Library/Application Support/TouchpadGestures/{config,appsettings,default}.json`
- **可随时重置**：设置页提供「重置全部」与「恢复代码默认值」
- **诊断日志默认为关**：开启后写入 `/tmp/touchpad_run.log`，排障完成后建议关闭

## 常见问题

### 菜单栏有图标，但手势没反应

1. 点菜单栏图标，看「触控板状态」是否显示「就绪」
2. 进「设置 → 手势健康」：红点表示该手势被引擎跳过（绑定失效或图不可执行）
3. 确认「系统设置 → 隐私与安全性 → 辅助功能」中已启用本 App

### 授权后仍提示未授予

ad-hoc 签名的 App，TCC 按「路径 + 签名身份（CDHash）」匹配。若系统里存在多份拷贝
（例如同时有「下载」和「应用程序」里的版本），授权可能落到了另一份上。

**处理**：只保留一份（建议放进「应用程序」），然后在设置页点「**重置授权**」重新授权。
本 App **不会**在启动时自动重置权限——那会清除你已授予的授权。

### 显示「已损坏」或无法打开

本 App 为 ad-hoc 签名，请**右键 →「打开」**，而不是直接双击。

### 滑动中调节中断 / 光标乱动

- 确认「鼠标锁定」已开启（手势期间光标应原地不动）
- 若仍异常，可在「设置 → 诊断日志」开启日志，终端 `tail -f /tmp/touchpad_run.log` 观察数据流

### 想恢复初始状态

「设置 → 配置默认值 → 恢复代码默认值」，或直接删除
`~/Library/Application Support/TouchpadGestures/` 下的配置后重启 App。

## 从源码构建与开发

### 环境

- macOS 15+，Xcode / Swift 工具链（`swift-tools-version: 6.0`，语言模式 Swift 5）
- 无需第三方依赖

### 运行与测试

```bash
git clone https://github.com/Zekilou/mac_touchpad.git
cd mac_touchpad

swift run TouchpadGestures     # 直接运行（调试）
swift test                     # 运行单元测试
```

### 打包分发包

```bash
./scripts/build_app.sh               # 正式版（release，不含诊断模块）
./scripts/build_app.sh dev           # 开发版（debug，含诊断模块）
./scripts/build_app.sh dev 输出目录   # 指定输出目录
```

产物为 `dist/TouchpadGestures.app` 与 `dist/TouchpadGestures.dmg`，并自动 ad-hoc 签名。

### 项目结构

| 目标 | 说明 |
|---|---|
| `GestureEngine` | 手势引擎库：节点图执行、配置模型与迁移、系统控制 |
| `mt_bridge` | MultitouchSupport C 桥接层 |
| `TouchpadGestures` | SwiftUI 菜单栏 App（主产品） |
| `TrackpadHIDTool` | 早期 IOKit 探索版本（保留作参考） |
| `GestureEngineTests` | 单元测试 |

### 诊断

- **设置 → 诊断日志**：开启后实时写入 `/tmp/touchpad_run.log`，可用 `tail -f` 观察手指 / 量化 / 进入 holding 的数据流
- **诊断模块**：仅 `#if DEBUG`（dev 构建）编译，包含崩溃捕获与诊断包导出；**正式版完全不含**
